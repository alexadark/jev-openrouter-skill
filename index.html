Structured judgment, not task execution

Choose the right model before the work begins.

Jev compares an explicit set of model profiles for the task you describe. It recommends one. You decide whether to switch.

The one sentence

Use Jev for a bounded recommendation, then select the model and reasoning effort manually in Codex.

First

Reliability

Prefer the profile most likely to stay correct across the whole task.

Second

Interventions

Reduce avoidable supervision, retries, and context recovery.

Third

Total cost

Count execution, validation, retries, and human recovery together.

02 · Keep the layers clear

The adviser is not the worker

Jev chooses among profiles. It does not do the task, authorize it, or change your model.

LayerRoleConsumption
CodexRuns the skill and can later perform the task.Native OpenAI models remain through your Codex subscription.
JevMakes one structured judgment from the supplied profiles.The consultation uses OpenRouter.
DeepSeekOptional execution model after a manual choice.DeepSeek V4.1 Flash uses Ollama Cloud and is consumed separately.

No automatic routing

The skill does not alter your active model, delegate the described work, or begin it. The model switch remains manual.

03 · Researched 2026-09-24

Use the smallest profile that preserves the outcome

Duration alone does not determine the model. Separate reasoning difficulty from step dependency, validation quality, autonomy, and the cost of a late error.

ProfileUse it forDo not treat it as
Luna · bounded and mechanical work
Luna LowShort translation, titles, simple reformulation, exact extraction, classification, targeted lookup.A fit for architecture, product judgment, or sensitive decisions.
Luna MediumBounded inventory, constrained extraction, a small known-cause fix with a clear test.Too small merely because the input is long.
Luna HighSubstantial bounded implementation, stable contracts, multi-step logic, observable tests.The default owner of a long unsupervised integration chain.
Luna XHighA bounded task with a concrete reasoning problem that High did not resolve.A routine setting. XHigh is exceptional.

Sol MediumFaithful synthesis, meeting preparation, polished writing, scoped comparison, everyday development, or a prolonged task with stable contracts and strong checks.A reason to ignore costly cross-system dependency risk.

Astra MediumLong dependent runs, multiple tools or components, costly late errors, architecture, ambiguous diagnosis, complex planning.A profile that first requires failure on a smaller model.
Astra HighA precisely identified critical difficulty not resolved at Medium, or clearly requiring deeper analysis.A permanent setting after the hard part is resolved.
Astra XHighExceptional complexity with a documented High-level impasse or equivalent evidence.An automatic choice for a large phase, long document, or important request.
Claude Opus 5.5Medium for coding and knowledge work. Low for bounded work; High, XHigh or Max for justified reasoning difficulty. Research and limits.Requires Claude Code or a verified Anthropic runtime and separate access. Not a native Codex model or a proven local winner over Astra.

Reasoning effort is not endurance

High and XHigh respond to identified reasoning difficulty. Long execution also depends on durable state, bounded steps, useful checks, and visible completion criteria.

04 · Codex-only v1

Install the skill

Use the agent skill installer for the preferred setup path.

$ npx skills add alexadark/jev-openrouter-skill --skill jev-openrouter

Manual fallback

Copy the entire skill directory. Cloning the repository directly into the Codex skills directory preserves every required file.

$ mkdir -p ~/.agents/skills
$ git clone https://github.com/alexadark/jev-openrouter-skill ~/.agents/skills/jev-openrouter

Set the key without saving it in the repository

Use your password manager, secret manager, or a protected shell environment. This temporary-session pattern keeps the value out of the command itself and out of shell history:

$ read -s "OPENROUTER_API_KEY?OpenRouter API key: "
$ export OPENROUTER_API_KEY

03

Restart. Start a fresh Codex session so it discovers the skill and inherits the variable.

Alpha endpoint

The skill calls OpenRouter's alpha Decisions endpoint. Its contract can change. A failed request should be reported, not silently replaced with the main model's opinion.

05 · Explicit invocation

Describe the decision, then stop

Name the skill, describe the future task, state provider or data constraints, and end with “Do not start the task.”

OpenAI-only example

Use $jev-openrouter to recommend the model and reasoning effort for:
Summarize a 90-minute customer interview into themes, evidence, risks, and next actions.
Use OpenAI profiles only.
Do not start the task.

Consider DeepSeek example

Use $jev-openrouter to recommend the model and reasoning effort for:
Classify 400 public product reviews into an existing taxonomy and return schema-valid JSON.
Ollama Cloud is available, these public reviews may be sent there, and preserving Codex quota matters.
Consider DeepSeek as well as OpenAI.
Do not start the task.

Useful constraints

  • Reasoning difficulty and ambiguity.
  • Independent or dependent steps.
  • Available automated checks.
  • Cost of an error found late.
  • Desired autonomy.

Leave out by default

  • The whole conversation.
  • An entire repository or vault.
  • Raw customer or employee records.
  • Credentials or private configuration.
  • Source text not needed for the choice.
06 · Interpret, do not overclaim

A recommendation has a narrow shape

A useful answer names one profile, explains the fit, gives a concrete reason to re-evaluate, and preserves the boundary between Jev's choice and Codex's explanation.

Recommendation: gpt-5.6-sol, Medium

Why: The task requires faithful synthesis and prioritization, but its sources,
output structure, and validation criteria are already bounded.

Re-evaluate if: contradictions across sources become material or the work expands
into a dependent multi-system implementation.

Jev choice: sol_medium, 0.62 among the supplied options
Decision model: shown only if returned by OpenRouter
Cost: shown only if returned by OpenRouter

Manual next step: select Sol and Medium in Codex if you accept the recommendation.

Illustrative format only. This is not a live Jev result or a performance claim.

Probabilities are choices, not success rates

A value such as 0.62 is Jev's preference among the options it received. It is not a 62 percent chance that the task will succeed, a calibrated reliability score, or a promised saving.

Only report returned identity

Name Jev's decision model and reported cost only when the OpenRouter response includes those fields. Never infer or promise an identity, cost, or outcome.

07 · Provider and data constraints

Eligibility comes before comparison

A model that cannot receive the data is not an option.

OpenAI only

Exclude Claude and DeepSeek before the Jev call. Compare only Luna, Sol, and Astra profiles allowed by the task.

Strictly local data

Exclude every cloud profile in this guide, including OpenAI, Claude and DeepSeek. Report that no profile is admissible.

DeepSeek is conditional

  • Confirm that Ollama Cloud and the exact model profile are currently available.
  • Confirm that the destination is permitted for the data.
  • Use a concrete reason, such as preserving Codex quota or reproducing a favorable verified comparison.
  • Do not describe it as local, included in Codex, or an automatic fallback.

More effort cannot repair missing authority

Tools, permissions, source access, and acceptance criteria are task constraints. No reasoning level can grant access, authorize a change, or replace a missing source.

08 · Common failures

When the advice path breaks

SymptomWhat to check
Skill not foundConfirm the repository is at ~/.agents/skills/jev-openrouter, then start Codex fresh.
API key unavailableExport OPENROUTER_API_KEY in the environment that launches Codex. Never put the value in the repository.
Request rejectedThe Decisions endpoint is alpha. Review the current OpenRouter and TypeSafe contract before changing the wrapper.
DeepSeek absentIt may have been filtered by an OpenAI-only or data rule, or Ollama Cloud availability may be unknown.
Advice feels overpoweredLook for a real reasoning difficulty, dependent steps, weak validation, or expensive late errors. Importance alone is not enough.
One profile remainsThe user's restriction already decides the choice. A Jev comparison adds no useful information.
No model identity or costThose fields are optional. Show them only when OpenRouter returns them.
